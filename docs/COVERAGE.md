## 检查方法（每个 Session 收尾执行，30 秒）

1. 打开本文件，逐行看「验收标准」列：有没有空着的？
2. 逐行看「实现归属」：这个模块真的存在吗？`Test-Path` 一下，别信记忆。
3. 更新「状态」列：本轮做完的改成 ✅ 或 🟡。
4. 如果本轮新增了 AC，同步加一行；如果发现某条需求没有 AC，**先补 spec 再做代码**。
5. 引用一次到 PROMPT_LOG 的收尾段落：本轮关掉了哪几行。
